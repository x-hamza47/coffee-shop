## About

Brewed Bliss is a front-end coffee shop website project. It presents a café brand with a clean landing page: a welcoming hero section, the story behind the shop, a visual menu of signature coffees, and a contact section with a map.

It is a good example of structuring a multi-section landing page with semantic HTML and hand-written CSS, with no frameworks or build tools.

## Features

- **Navigation bar** with smooth in-page anchor links (Home, About, Categories, Contact)
- **Hero section** with a headline and call-to-action button
- **About Us section** telling the brand story, with a featured image
- **Coffee selection** with six menu cards, each with an image, description, and "Learn More" link
- **Contact section** with a message form (name, email, message) and an embedded Google Map
- **Footer** with about text, quick links, address, email, phone, and copyright notice
- **Zero dependencies:** no frameworks, no build step, no JavaScript

## Getting Started

No installation or build tools are needed.

```bash
# Clone the repository
git clone https://github.com/x-hamza47/coffee-shop
cd coffee-shop
```

Then open `index.html` in your browser. To serve it locally instead:

```bash
# Using Python
python -m http.server 8000

# Or using the VS Code "Live Server" extension
```

Visit `http://localhost:8000` in your browser.
